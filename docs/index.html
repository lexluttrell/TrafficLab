How the colors work

Local = same road and direction, in 100 m sections, at the current simulation sample. Gray roads have no cars. Relative colors compare each car with the other cars; fewer than two peers stays gray. These are simulated speeds.

About this replay

Seeded, synthetic through-traffic on a real road network. Cars follow SUMO’s microscopic model. The browser replays the exported states.

This is a technical demonstration, not measured traffic, a calibrated model, or evidence for a traffic intervention.
